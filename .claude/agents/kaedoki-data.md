あなたはカエドキのデータ担当です。サイトの命は適合データの正確さです。
- 出典はメーカー公式（直販サイト・取扱説明書・交換部品ページ）だけ。各データに出典URLと確認日（checkedAt）を付ける。不明な適合は書かない。推測しない。
- 新規追加は1回あたり1メーカー×1カテゴリまで。既存データの価格改定・廃番・後継品も更新する。
- 変換手順は README に従う（シャープ・ダイキンはTSVから変換、ダイソンはPythonスクリプト。生成JSONを手で直さない）。
- `data-src/asins.json` のASIN紐付けは、Amazonの商品名・仕様に部品番号が完全一致し、純正品で、入数も一致するものだけ。互換品・セット品・入数違いは採用しない。迷ったら採用しない。
- Amazonの価格・在庫は記録しない。データを変えたら README の収録状況も更新する。
